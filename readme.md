Для запуска хоста необходимо иметь файл ".env" в корне проекта (там же, где этот файл, который Вы сейчас читаете).\
В этом файле необходимо иметь переменные среды API_KEY и API_URL: для хранения токена API и для адреса этого API соотвественно.\
Также нужно иметь переменную SECRET_KEY, использующуюся для генерации и верификации JWT-токенов.\
Вдобавок к этому - поля SENDER_EMAIL и SENDER_PASSWORD для электронной почты и пароля SMTP-клиента соотвественно: с них будет отправляться код подтверждения при регистрации пользователя.

Пример:
```
API_URL=https://someapi.com/v1
API_KEY=9999999JJJJJ88888JJJJJ
SECRET_KEY=mysecretpassphrase
SENDER_EMAIL=mymail@somemail.com
SENDER_PASSWORD='some pass word 4x4s'
```

В файле "REST endpoints.md" описаны все актуальные эндпойнты
