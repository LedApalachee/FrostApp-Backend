# Спецификация REST API SmartFrost App  за 26.05.2026

### POST /users
Первый этап регистрации. Высылает на указанную почту шестизначный код для ее подтверждения - см. эндпойнт "GET /users/verify"\
Не создает в БД запись о новом пользователе - этим занимается упомянутый выше эндпойнт.\
Коды подтверждения можно посылать сколько угодно, используя этот эндпойнт.

Тело запроса:
* name - строка; имя пользователя
* email - строка; на эту почту высылается код подтверждения
* password - строка

Тело ответа:
* message - строка:\
"vercode sent", если код подтверждения отправлен успешно\
"email exists", если в БД уже есть пользователь с такой почтой

### GET /users/verify
Второй этап регистрации. После успешного подтверждения почты в БД создается запись о новом пользователе.

Параметры в URL:
* email - строка; почта, на которую пришел код подтверждения
* vercode - строка; код подтверждения

Тело ответа:
* message - строка:\
"success", если почта успешно подтверждена и в БД занесён новый пользователь\
"incorrect", если код подтверждения или электронная почта указаны неверно
* user_id - int; идентификатор нового пользователя
* token - строка; JWT-токен для авторизации

### GET /users
Возваращает данные указанного пользователя; поиск по user_id

Параметры запроса (параметры указываются в самом URL):
* user_id - идентификатор пользователя
* token - JWT-токен

Тело ответа:
* message - строка;\
"success", если пользователь найден и авторизован\
"bad token", если токен не действителен\
"user not found", если пользователь не найден
* user - объект со следующими полями: id (int), name (str), email (str)

### POST /login
Выполняет аутентификацию по почте и паролю

Тело запроса:
* email - строка
* password - строка

Тело ответа:
* message - строка;\
"success", если аутентификация прошла успешно\
"incorrect", если пользователя не существует, либо данные неверные
* user_id - int; идентификатор аутентифицированного пользователя
* token - строка; JWT-токен для авторизации

### GET /items
Возвращает список продуктов данного пользователя

Параметры в URL:
* user_id - идентификатор пользователя
* token - JWT-токен

Тело ответа:
* message - строка:\
"success", если успешно и список продуктов найден\
"bad token", если токен недействителенf
* items - массив объектов, имеющих следующие поля: id (int), user_id (int), name (str), expiration (str), deleted (bool)

### POST /items
Добавляет продукты данного пользователя

Тело запроса:
* user_id - int
* items - массив объектов с двумя полями: name (str), expiration (str | null)
* token - строка

Тело ответа:
* message - строка;\
"success", если операция прошла успешно\
"bad token", если токен не действителен

### POST /items/delete
Удалить определенные продукты данного пользователя.\
(на самом деле продукты не удаляются из БД моментально, а помечаются на удаление - поле "deleted")

Тело запроса:
* item_ids - массив int-ов - идентификаторов продуктов, которые нужно удалить
* user_id - int; идентификатор пользователя, чьи продукты удаляем
* token - JWT-токен

Тело ответа:
* message - строка;\
"n items deleted" - если пользователь найден и авторизован\
"bad token" - если токен недействителен

### PUT /items
Обновить данные указанных продуктов

Тело запроса:
* user_id - int; идентификатор пользователя, чьи продукты затрагиваем\
* token - строка; JWT-токен
* items_upd - массив следующего вида:
```
"items_upd": [
    // n - int; ID продукта
    // field1, field2 - поля, которые хотите обновить, а рядом  - новое значение поля
    // обновятся только те поля, которые указаны
    // поля "id", "user_id", "deleted" обновить нельзя
    [n, {"field1": ..., "field2": ..., ...}],
    [n, {"field3": ..., "field4": ..., ...}]
]
```

Тело ответа:
* message - строка:\
"n items updated"; обновлено n товаров\
"bad token", если токен недействителен

### POST /qr-text
Ищет купленные товары на стороннем API по заданному значению из QR-кода

Тело запроса:
* qrraw - строка вида "t=20260517T131059&s=554.01&fn=7380440902180698&i=57213&fp=2292136839&n=1"
* token - JWT-токен
* user_id - int

Тело ответа:
* message - строка:\
"success", если данные по QR-коду успешно найдены\
[название ошибки], если не получилось достать данные с proverkachecka.com\
"bad token", если токен недействителен
* items - массив объектов с полями "name" (str), "quantity" (float), "unit" (str)
