## Goals

### Распознание текста
1. На сервер приходит изображение
2. С помощью библиотек, происходит его распознание Image-to-Text
3. Работа с LM Studio
    1) Создание сервера с LLM
    2) Отправка на него этого текста с промптами, для корректной обработки
    3) Возвращение обратно файла со списком

### Рецепты
1. На сервер приходит запрос от пользователя, о том, что он хочет получить список рецептов из имеющихся продуктов
2. Сервер отправляет промпт + запрос пользователя + blacklist.json на сервер LLM
3. LLM с подключенным модулем на поиск в интернете ищет и перепроверяет результаты
4. Возвращает его обратно на сервер в виде файла

## LLM-Model
Обращение к локальной LLM-модели
Модель:
- https://lmstudio.ai/models/google/gemma-4-e4b

Функции:
1. Классификация и составление списка предметов
2. Поиск рецептов в Интренете

blacklist.json - какие сайты строго нельзя посещать ИИ
